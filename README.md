# Currency Converter Project

A Java-based Currency Converter application designed to convert values between different global currencies. This repository contains both the core application logic and its software testing framework.

## 🚀 Features
* Live currency conversion values.
* Built using Java and managed with Maven (`pom.xml`).
* Clean project architecture separation (`src/` folder).

## 🛠️ Tech Stack & Tools
* **IDE:** IntelliJ IDEA
* **Language:** Java
* **Version Control:** Git & GitHub
* **Build Tool:** Maven

## 🧪 Software Testing
This project includes automated testing suites to verify processing accuracy:
* Unit tests for core calculation functions.
* Boundary and validation checks for exchange rates.
